FT-039 — Suporte a Profiling Nativo (Flamegraphs)
Module: Core Governance | Version: v0.1 | Priority: P2 — Medium
Artifact ID: FT-039-FLAMEGRAPH-PROFILER | Updated: 2026-09-26

1. Context and Objective
Para garantir que a meta de latência de microssegundos está sendo cumprida e provar que o motor de redes é estritamente zero-copy, habilitamos a coleta de profiles de CPU nativos usando ferramentas como pprof ou perf do Linux em produção.

2. Acceptance Criteria (AC)
Specific

AC-010: Implementação da feature flag --enable-profiling no boot do nó (FT-001).

AC-011: Integrar a crate pprof ou equivalente que permite extração interativa de Flamegraphs do processo KinePlex em execução via endpoint HTTP /debug/pprof/flamegraph.

AC-012: Símbolos de debug e flags de linkagem (no Cargo.toml) ativados mesmo em --release (ex: debug = 1) para não ocultar nomes de funções críticas na árvore de chamadas.

3. Definition of Done (DoD)

Relatório gerado consegue mapear corretamente o limite entre o host Rust e o guest Wasm.

Aviso em log de que o profiling adiciona leve penalidade de latência.
