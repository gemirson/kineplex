FT-034 — Utilitário de Leitura Nativa (Receptor Parquet/CSV)
Module: Client API / Engine | Version: v0.1 | Priority: P0 — Critical
Artifact ID: FT-034-SOURCE-RECEPTOR | Updated: 2026-09-19

1. Context and Objective
Para o Grafo iniciar, os dados precisam nascer. O Nó instanciado como "Receptor" (a primeira etapa do DAG) não lê da rede QUIC. Ele lê blocos de disco físico (ou Object Storage S3). Ele atua como um disparador inicial (Seed Engine), transformando o disco no formato Arrow e iniciando os Spikes.

2. Acceptance Criteria (AC)
Specific

AC-010: Integração com a crate parquet para leitura direta para os buffers Arrow (Zero-Copy onde aplicável).

AC-011: Leitura assíncrona paginada (Stream). O Receptor não pode carregar um arquivo de 10GB na RAM de uma vez. Ele lê pedaços exatos que correspondam ao gatilho do Acumulador (ex: 64KB) e injeta no fluxo QUIC.

AC-012: Controle de Throttle local (Backpressure): Se a malha QUIC sinalizar lentidão, a leitura do disco é pausada.

3. Definition of Done (DoD)

Uso de tokio::fs para I/O assíncrono.

Teste E2E: Leitura de um arquivo parquet local de 100MB dividindo-o perfeitamente em múltiplos Spikes, enviados via canal loopback.
