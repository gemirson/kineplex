FT-032 — Abstrações Idiomáticas do SDK Arrow
Module: SDK | Version: v0.1 | Priority: P1 — High
Artifact ID: FT-032-SDK-ARROW-ABSTRACTIONS | Updated: 2026-09-19

1. Context and Objective
A API bruta do arrow-rs pode ser verbosa para operações simples (exigindo downcast_ref para extrair um vetor primitivo). O SDK do KinePlex fornecerá traits de extensão (Extension Traits) para permitir uma sintaxe fluente e segura por parte do desenvolvedor.

2. Acceptance Criteria (AC)
Specific

AC-010: Trait KineColumnExt injeta o método .column_as_i32("nome") e variantes para RecordBatch.

AC-011: Garantia de tipagem segura (Type-Safety) que retorna erro propagável se o usuário pedir i32 de uma coluna que fisicamente é Float64.

AC-012: Exposição de construtores de lote simplificados (Builder Pattern) para o usuário emitir os resultados.

3. Definition of Done (DoD)

Testes unitários cobrindo todos os tipos primitivos Arrow base suportados (Inteiros, Floats, Strings, Booleans).

Implementações sem cópia de dados (as abstrações retornam slices &[T] diretamente do buffer Arrow subjacente).
