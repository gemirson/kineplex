FT-023 — FFI e Arrow C Data Interface (Exportação Host)Module: Core Engine | Version: v0.1 | Priority: P0 — CriticalArtifact ID: FT-023-ARROW-FFI-EXPORTS | Updated: 2026-09-191. Context and ObjectiveA magia do Zero-Copy entre o Rust e o Wasm. O wasmtime isola a memória linear. Para passar os dados do Arrow sem copiar os gigabytes de dados que chegaram do io_uring, usamos a especificação formal "Arrow C Data Interface". O Host (Rust) exporta a estrutura de ponteiros físicos de suas arrays e passa apenas o endereço u32 / u64 para o Guest Wasm.2. Acceptance Criteria (AC)SpecificAC-010: Conversão de um RecordBatch gerido pelo crate arrow-rs em structs brutas FFI_ArrowArray e FFI_ArrowSchema.AC-011: O KinePlex aloca um espaço minúsculo na Memória Linear da instância Wasm (usando a função Wasm exportada alloc_ffi), envia a struct FFI contendo os ponteiros lá para dentro.AC-012: O memory allocator do Wasm deve reconhecer o ponteiro e tratar o bloco de memória mapeado como um ArrayData válido do Arrow.3.
