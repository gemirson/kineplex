FT-027 — Consolidador de Memória (Concatenação Arrow Zero-Copy)
Module: Core Engine | Version: v0.1 | Priority: P1 — High
Artifact ID: FT-027-ARROW-CONCAT | Updated: 2026-09-19

1. Context and Objective
O Wasmtime e os núcleos SIMD nativos perdem eficiência se iterarem 10 vezes em arrays de 100 elementos em vez de 1 vez em um array de 1000 elementos. Quando o Acumulador "dispara", ele possui N pequenos RecordBatches. Esta feature utiliza o crate nativo para concatenar logicamente esses pedaços em um único Batch maior antes de entregar para processamento, otimizando o cache L1/L2 do processador.

2. Acceptance Criteria (AC)
Specific

AC-010: Recebe o vetor de RecordBatches acumulados e usa arrow::compute::concat sobre as colunas subjacentes.

AC-011: Validação rigorosa de Schema: garante que todos os micro-lotes do Spike possuem a mesma tipagem e ordem antes de fundir.

AC-012: Emite Err(SchemaMismatch) se um nó remoto enviou lixo ou alterou a coluna em trânsito.

3. Definition of Done (DoD)

Nenhum pânico, mesmo se os micro-lotes somarem mais de usize::MAX (deve ser barrado no limite estrito por chunk).

O lote resultante é um RecordBatch único validado semanticamente.

6. CARE Format
Context: O cérebro Wasm precisa de um bloco contíguo de FFI para usar prefetching da CPU. Concatenar no host (Rust) é mais barato que iterar pequenos arrays via boundary do Wasm.
Requirements: R-001: Função pura (Array[N] -> Array[1]) | R-002: Proteção OOM (limite superior do lote).
