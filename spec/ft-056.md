FT-056 — Isolação Estrita entre Control Plane (Geometria) e Data Plane
Module: Core Governance | Version: v0.2 | Priority: P0 — Critical

Artifact ID: FT-056-PLANE-ISOLATION

Context & Objective: Blindar o motor de dados contra qualquer interferência da camada matemática. O Control Plane roda em threads de baixa prioridade e o Data Plane (io_uring + Wasm) roda em isolamento absoluto.

Acceptance Criteria: Nenhuma operação geométrica pesada executa na thread de I/O de rede; uso estrito de canais não-bloqueantes (crossbeam / Tokio) para troca de metadados.

Definition of Done: Perfilamento de CPU (Flamegraph) atestando 0% de contaminação do loop de I/O por cálculos de tensores.
