FT-037 — Submissão de Job Completo (KinePlex CLI Injetor)
Module: Client SDK | Version: v0.1 | Priority: P0 — Critical
Artifact ID: FT-037-JOB-SUBMIT-CLI | Updated: 2026-09-26

1. Context and Objective
Os desenvolvedores criaram o grafo via SDK (FT-033). Agora precisam injetar isso no cluster distribuído. O binário utilitário kineplex-cli submit fará o empacotamento das UDFs compiladas (binários .wasm), resolverá as dependências do DAG e as transmitirá ao Semeador.

2. Acceptance Criteria (AC)
Specific

AC-010: Comando kineplex-cli submit <job.yaml/json> --seed 192.168.1.10:8000.

AC-011: A CLI lê todos os arquivos .wasm referenciados no descritor, encodifica-os em Base64 ou binário gRPC multipart, e despacha no endpoint de Control Plane (FT-006).

AC-012: A CLI exibe uma barra de progresso em tempo real capturando o status de alocação de cada nó via Control Plane até o estado RUNNING.

3. Definition of Done (DoD)

Feedback de terminal amigável e parse rigoroso de erros (ex: "Wasm file not found").

A CLI bloqueia a execução até que o Semeador confirme que o Grafo foi 100% alocado, retornando código de saída 0 no sucesso e 1 na falha (amigável para CI/CD).
