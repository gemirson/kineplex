FT-064 — RCU (Read-Copy-Update) para a Matriz Geodésica
Module: Kernel Driver | Version: v0.3 | Priority: P0 — Critical

Context & Objective: O estilo arquitetural do Kernel Linux abomina locks tradicionais (Mutex/Spinlocks) em caminhos de leitura pesados. A matriz de roteamento geodésico será gerida via RCU, garantindo que o hardware leia rotas antigas sem blocking enquanto a rota nova é matematicamente atualizada no background.

Acceptance Criteria: O ponteiro da matriz usa a API rcu_dereference; atualizações de tensores usam rcu_assign_pointer e synchronize_rcu().

Definition of Done: Validação com a ferramenta de debug do kernel PROVE_RCU (Lockdep) certificando a ausência de violações e deadlocks.
