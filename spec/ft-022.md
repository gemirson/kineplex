Context and ObjectiveQuando o Semeador avisa um Nó B que ele precisa processar o módulo meu_filtro.wasm, esse bytes Wasm podem chegar pela rede ou já estarem no cache do disco local. O Nó deve compilar esse Wasm em código de máquina nativo (JIT via Cranelift) da forma mais rápida possível.2. Definition of Done (DoD)Testes atestando que carregar o mesmo binário 10 vezes resulta em apenas 1 ciclo de compilação (hit no cache).Se o byte array for malformado (não for Wasm válido), retorno de erro customizado descritivo.6.
