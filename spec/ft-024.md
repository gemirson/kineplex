FT-024 — Leitura de Memória Host pelo Guest Wasm
Module: Core Engine | Version: v0.1 | Priority: P0 — Critical
Artifact ID: FT-024-WASM-MEMORY-READ | Updated: 2026-09-19

1. Context and Objective
Agora que o Wasm recebeu o ponteiro FFI (FT-023), como ele processa isso? Precisamos configurar a wasmtime::Memory para que o Guest (UDF Wasm do usuário) consiga ler diretamente da RAM física do Host de forma segura e vetorizada, sem disparar "Out Of Bounds" (Acesso a endereço inválido).

2. Acceptance Criteria (AC)
Specific

AC-010: O KinePlex repassa as referências da memória Arrow como uma região Read-Only compartilhada para o Wasm.

AC-011: No Wasm, as primitivas matemáticas e lógicas devem iterar sobre essa memória mapeada aproveitando o formato colunar para cache de CPU (ex: iteração contígua for i in 0..len).

AC-012: Proteção: O Wasm é proibido pelo Host de modificar o array de entrada.

3. Definition of Done (DoD)

Teste unitário E2E: Wasm soma todos os itens da coluna "score" (Float32). O Host valida que o valor de retorno bate com o cálculo local feito no Rust.

Benchmark provando latência idêntica a ponteiros C.
