FT-033 — Construção Declarativa: KineGraph Builder
Module: Client API | Version: v0.1 | Priority: P0 — Critical
Artifact ID: FT-033-GRAPH-BUILDER | Updated: 2026-09-19

1. Context and Objective
É a forma como o usuário submete trabalho. Em vez de escrever o JSON bruto que definimos no FT-006, o engenheiro usa uma API cliente fluente (Fluent Builder) em Rust (que pode ser mapeada para Python/PyO3 no futuro) para definir o fluxo lógico de dados.

2. Acceptance Criteria (AC)
Specific

AC-010: Criação de um DAG Builder KineGraph::new().

AC-011: Suporte aos métodos .receptor(), .synapse_wasm("arquivo.wasm"), .synapse_native(Operator), e .terminal().

AC-012: O builder implementa um método estático build() que converte o fluxo encadeado no payload JSON/Protobuf padrão.

3. Definition of Done (DoD)

Mecanismo de linkagem automática: se o usuário chamar A.synapse(B), a aresta A->B é criada internamente no Grafo.

Validação em client-side da mesma lógica DFS de ausência de ciclos, evitando enviar lixo para a rede.

4. Usage Examples
Input (Client Rust):

Rust
let graph = KineGraph::new()
    .receptor("s3://data/input.parquet")
    .synapse_wasm("target/wasm32/release/filter.wasm")
    .terminal("s3://data/output/");
