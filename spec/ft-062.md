FT-062 — Character Device e Memória Compartilhada Zero-Copy (mmap)Module: Kernel Driver | Version: v0.3 | Priority: P0 — CriticalContext & Objective: O userspace (engine KinePlex) precisa ler as rotas calculadas pelo kernel sem fazer syscalls de leitura pesadas. O driver expõe um dispositivo /dev/kinegeo que o KinePlex mapeia na RAM física.Acceptance Criteria: Implementação das file operations open, release e mmap. O mmap deve apontar para as páginas de RAM onde o kernel deposita a tabela de roteamento geodésico vetorizada.Definition of Done: KinePlex userspace lê a matriz geodésica alocada pelo kernel apenas lendo um ponteiro Rust cru (*const u8), com $0$ syscalls no hot path.
