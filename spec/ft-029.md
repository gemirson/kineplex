FT-029 — Construção do Spike de Saída (Engate na Transmissão)
Module: Core Engine | Version: v0.1 | Priority: P0 — Critical
Artifact ID: FT-029-SPIKE-EGRESS | Updated: 2026-09-19

1. Context and Objective
A propagação sináptica. O processamento no nó acabou e resultou em um lote limpo de dados. Ele deve ser re-encapsulado no padrão de rede (FlatBuffers) e empurrado para o io_uring (Writev), completando o ciclo do fluxo de dados e mandando a carga de volta para os axônios (QUIC).

2. Acceptance Criteria (AC)
Specific

AC-010: O resultado FFI é transformado de volta em um RecordBatch idiomático em Rust.

AC-011: Invoca-se o serializador Arrow IPC padrão para transformar em bytes de rede &[u8].

AC-012: A função build_synapse_header (FT-013) é chamada para carimbar o seq_num atualizado e o tamanho do pacote.

AC-013: Os ponteiros (Header + Payload) são submetidos à Submission Queue do io_uring (FT-020).

3. Definition of Done (DoD)

Garantia de ordenação: a variável seq_num por sinapse aumenta monotonicamente (Thread-safe atomics ou locks de loop de Sinapse exclusivos).

Benchmark mostrando ciclo ponta a ponta (Arrow IN -> FFI -> Wasm -> FFI -> Arrow IPC OUT) menor que 2 milissegundos para lotes de 10k registros.
