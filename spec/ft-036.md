FT-036 — Interface de Observabilidade Neural (Spike Tapping)Module: Core Observability | Version: v0.1 | Priority: P1 — HighArtifact ID: FT-036-SPIKE-TAPPING | Updated: 2026-09-261. Context and ObjectiveEm uma rede neural biológica ou num cluster de alta frequência, precisamos de ferramentas como um "analisador lógico" para debugar pacotes em tempo real. O Spike Tapping permite que um desenvolvedor se conecte a uma Sinapse ativa e intercepte uma cópia dos cabeçalhos FlatBuffers (FT-013) fluindo, de forma passiva, como um Wireshark interno.2. Acceptance Criteria (AC)SpecificAC-010: Endpoint gRPC/TCP no Control Plane que aceita conexões de subscrição de log (SubscribeTapping(GraphID, SynapseID)).AC-011: O Motor de I/O replica as referências de memória apenas do Header (ignorando a carga de dados pesada do Arrow) e envia assincronamente para o subscritor conectado.AC-012: Zero impacto no fluxo principal: se o buffer do cliente TCP encher, os logs de tapping são descartados (drop) sem fazer backpressure no Data Plane do io_uring.3. Definition of Done (DoD)A interceptação deve operar na camada de multiplexação QUIC (lendo a variável seq_num e flags).Teste de concorrência atestando que ligar/desligar o Spike Tapping causa $\le$ 1% de variação no throughput geral da sinapse.
