FT-028 — O Disparo Neural: Invocação do Wasm
Module: Core Engine | Version: v0.1 | Priority: P0 — Critical
Artifact ID: FT-028-WASM-INVOCATION | Updated: 2026-09-19

1. Context and Objective
A execução real da UDF do usuário. O lote Arrow consolidado (FT-027) teve seus ponteiros exportados para o padrão Arrow C Data Interface (FT-023). O KinePlex agora desperta a Máquina Virtual do WebAssembly, entrega os ponteiros e extrai o resultado da memória linear.

2. Acceptance Criteria (AC)
Specific

AC-010: O Host invoca a função Wasm padronizada kineplex_run(input_ptr: i32, input_schema: i32) -> i32 na instância instanciada no FT-021.

AC-011: O retorno i32 do Wasm é tratado como um ponteiro dentro da memória linear do Wasm. O KinePlex lê este ponteiro usando a API FFI FFI_ArrowArray::empty() + import().

AC-012: Captura de erro (Trap): Se a UDF divir por zero ou estourar a memória, a engine Wasmtime emite um Trap. O Rust captura e encapsula em um erro local (abortando apenas a Sinapse, não o Nó inteiro).

3. Definition of Done (DoD)

Nenhum unsafe block associado à leitura do retorno FFI que não possua tratamento explícito de verificação de limites (Bounds Checking contra o tamanho máximo da Linear Memory do Wasm).

Teste de Integração onde um módulo Wasm de filtro recebe 100 linhas e retorna 50 linhas, e o RecordBatch extraído pelo Rust bate perfeitamente com as 50 linhas esperadas.
