FT-025 — Caminho Rápido Nativo (Filtros SIMD em Rust)
Module: Core Engine | Version: v0.1 | Priority: P1 — High
Artifact ID: FT-025-NATIVE-FAST-PATH | Updated: 2026-09-19

1. Context and Objective
Se um cliente enviar um comando simples no Grafo, como "Filter column > 10", seria um desperdício invocar toda a maquinaria FFI e Wasm. Para operações relacionais básicas, o KinePlex deve contornar o Wasm e usar as funções (kernels) SIMD brutalmente otimizadas da própria crate nativa arrow::compute do Rust.

2. Acceptance Criteria (AC)
Specific

AC-010: Estrutura PhysicalPlan::FilterNode recebe o buffer Arrow do io_uring diretamente.

AC-011: Utilização de kernels vetorizados (arrow::compute::filter, arrow::compute::cmp::gt, etc) que processam lotes de 64 registros simultaneamente nos registradores AVX2/AVX-512 do processador.

AC-012: O resultado (novo RecordBatch filtrado) flui para a etapa de Spiking Dataflow para ser empacotado e enviado via QUIC (FT-014).

3. Definition of Done (DoD)

Benchmark base (Criterion) com throughput massivo (exigência: processar array Float32 de 10 milhões de itens em menos de 1 milissegundo).

Tratamento unificado da API: O resto do pipeline não percebe a diferença se o lote foi filtrado via Wasm ou via Caminho Nativo.
