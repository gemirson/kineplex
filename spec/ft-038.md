FT-038 — Exposição de Métricas Prometheus / OpenTelemetry
Module: Core Observability | Version: v0.1 | Priority: P1 — High
Artifact ID: FT-038-PROMETHEUS-EXPORTER | Updated: 2026-09-26

1. Context and Objective
Para rodar em produção, o KinePlex precisa ser escrapeado por ferramentas padrão de mercado. Esta feature converte as telemetrias internas coletadas via Gossip e sysinfo em séries temporais padronizadas.

2. Acceptance Criteria (AC)
Specific

AC-010: Exposição de um endpoint /metrics na mesma porta de Control Plane usando o formato de texto do Prometheus.

AC-011: Métricas obrigatórias exportadas: kineplex_spikes_total (counter), kineplex_arrow_bytes_total (counter), kineplex_wasm_execution_ms (histogram) e kineplex_cqe_drops (counter de pacotes dropados no io_uring).

AC-012: Inclusão das métricas topológicas e tensores de curvatura (da nossa recente atualização geométrica).

3. Definition of Done (DoD)

Endpoint não bloqueante e com cache de 1 segundo para evitar DDoS acidental de scrapers agressivos.

Grafana Dashboard (arquivo .json) provisionado na pasta docs/ com os painéis principais do sistema.
